# Databel-Customer-Churn-Dashboard-
Power BI dashboard analyzing Customer Churn Analysis
📊 Customer Churn Analysis – Power BI (Databel Dataset)
🧠 Project Overview
This project analyzes customer churn patterns using Power BI to identify key drivers of customer loss and provide actionable business recommendations.

## Tools & Skills Used
-  Power BI
-  DAX (Calculated measures, SWITCH, IF logic)
-  Data cleaning & transformation
-  Data visualization (Maps, KPIs, Charts)
-  Customer segmentation

## Process
-  Data exploration and validation
-  Data cleaning and standardization
-  Created DAX measures (Churn Rate, Customer Count, Unique Customers)
-  Built customer segments (age, tenure, contract type)
-  Designed interactive dashboard with filters and visuals

## Key Insights
-  Overall churn rate: 26.86%
-  73.55% of churn driven by competitors
-  California had highest churn: 63.24%
-  Seniors had highest churn: 38.46%
-  Monthly contracts churn ~7x more than yearly
-  New customers (0–12 months) most likely to churn

## Recommendations
-  Improve retention in high-risk regions
-  Promote yearly subscription plans
-  Strengthen onboarding for new users
-  Review pricing for unlimited plans

📌 Outcome
This analysis demonstrates how data-driven insights can directly support customer retention strategies.
